在智能体卡片上有一个"会话"栏，在 A2A 协作卡片上又有一个会话台

前者是 Agent 的对话记忆

在会话栏里填一个标识，这个 Agent 在 ReAct 循环里就有了跨运行的历史。

执行前 recall() 读一次，把最近若干轮渲染成成对的 User/Assistant 消息前置在当前提问之前；
执行成功后 record() 把这一轮写回去。

用处就是让同一个 Agent 记得住上一句
不填就是每次从零开始，行为和"没有记忆功能"逐字一致。

点击新会话按钮就是换一个 id，等于开一段新历史，旧的还在（TTL 内）但不再被读

后者是 Agent 之间的通信记录

它的两个用处：

它是委派唯一的通道。消息不另开投递路径，落一次盘、跨实例只发一个唤醒。所以"它们之间能通信"这件事只有这一个真相来源。

它是留痕。普通工具调用只在你模型的上下文里留一行 Observation，出了这个 Agent 就看不见了
而会话台能逐条看到谁在第几轮问了什么、对方回了什么。选一场会话之后是按 seq 游标轮询拉增量（GET.../messages?after=N），所以跑着的会话能实时看。
