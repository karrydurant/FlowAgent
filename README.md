# FlowAgent 

### 项目定位

一个服务于魔搭的简易多 Agent 工作流搭建与协作平台。你只需输入自己的魔搭访问令牌，就能在创建智能体时为智能体配置模型（目前仅支持全局统一），给他们装备魔搭上你事先部署好的工具，然后进行任务的编排。

### 使用说明
输入你的魔搭令牌后，可以在 "全局大模型" 卡片查看有哪些可以接入的模型。

你可以使用画布进行拖曳+连线式的编排，[9种节点](docs/nodes.md) 包含了人工审批，Agent互相委派，Agent互相协商等功能。另外如果不清楚怎么为节点配置 "提示词"，"议题" 这类要主管输入的部分（比如你需要指明让一群智能体节点围绕上个智能体的回答进行讨论）你可以在有箭头连接的前提下点击选择上游节点，再点击选择字段来帮助完成提示词的书写
